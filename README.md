## 🚀 Projetos em destaque

**[CourseSphere](https://github.com/BezerraFilipe/CourseSphere)** · [Demo](https://coursesphere-front.vercel.app)
Plataforma de gestão de cursos online com API REST em Ruby on Rails 8.1 (API mode), frontend em React 19 + TypeScript e PostgreSQL 15. Autenticação por token, controle de acesso, Docker Compose e deploy em produção.

**[Learning FastAPI](https://github.com/BezerraFilipe/learning-fast-api)** · *em desenvolvimento*
API REST assíncrona com FastAPI, autenticação JWT, validações com Pydantic, migrations com Alembic, testes com pytest e pipeline de CI com GitHub Actions.

**[Cacheese](https://github.com/BezerraFilipe/cacheese)** · *em desenvolvimento*
Aplicação full-stack de gestão financeira em Ruby on Rails 8 com PostgreSQL, testes com RSpec e FactoryBot, integração com a OpenAI API, deploy com Kamal e CI com GitHub Actions.

**[NutriChefAI](https://github.com/BezerraFilipe/NutriChefAIFork)** · [Demo](https://nutri-chef-ai.vercel.app)
Aplicação web colaborativa desenvolvida em equipe na UFPE com Next.js, TypeScript, Prisma ORM e testes com Jest.
